# Implementation Plan

- [x] 1. データモデルと共通基盤の整備
- [x] 1.1 OSCトリガーボタンとパネル設定のデータモデルを定義し、プロジェクト永続化に統合する
  - グリッド寸法（行数・列数）とボタン集合（位置・ラベル・アドレス・引数・送信先）を表すモデルを追加する
  - プロジェクトデータに新セクションを追加し、既存のJSON設定（camelCase・既存の引数コンバータ）で保存・読込できるようにする
  - 旧プロジェクトファイル（新セクションなし）を既定値で読み込めるよう後方互換を確保する
  - _Requirements: 2.1, 2.3, 5.1, 5.3, 5.5_

- [x] 1.2 (P) OSC引数テキスト記法の共通ヘルパを抽出する
  - 既存キュー編集の `i:/f:/s:` 記法のパース・整形ロジックを共通ヘルパへ切り出す
  - 既存キュー編集ダイアログを共通ヘルパ利用に置き換え、挙動の同一性を保つ
  - _Requirements: 3.4_

- [x] 2. OSCトリガーパネルの状態管理・送出サービスを実装する
- [x] 2.1 グリッド構成とボタンの状態保持・CRUDを実装する
  - 行・列の寸法とボタン集合を保持し、セル単位の取得・追加更新・削除を提供する
  - 同一セルに複数ボタンが存在しない不変条件を保証する
  - 行・列の最小値（1）を下回る指定を拒否し、縮小時に範囲外となるボタンを列挙できるようにする
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5_

- [x] 2.2 ボタン押下による即時OSC送出を実装する
  - 既存のOSC送出口を用いて、設定済みボタンのアドレス・引数を送信先へ即時送出する
  - 送信先が未設定・全無効、または未設定セルの場合は送出せず理由を返す
  - 送出はタイムコードの進行状態に依存せず実行され、結果が既存ログ機構に記録されることを確認する
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.6, 6.1, 6.2_

- [x] 2.3 パネル設定の保存・復元・初期化を実装する
  - 現在のグリッド・ボタン状態を永続化用に出力し、保存データから復元、新規時に既定化する手段を提供する
  - 状態変更通知を提供し、未保存変更の検知に連携できるようにする
  - _Requirements: 5.1, 5.2, 5.4_

- [x] 3. ボタン設定の編集UIを実装する
- [x] 3.1 ボタン編集ダイアログを実装する
  - ラベル・OSCアドレス・引数・送信先ホストを編集できるダイアログを、既存ダイアログ様式とダークテーマで作成する
  - OSCアドレスの形式検証（空不可・`/` 始まり）と、引数の共通記法によるパースを行う
  - 送信先ホストを既存ホスト一覧から複数選択できるようにする
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5, 3.6, 6.3_

- [x] 3.2 編集ダイアログ表示サービスを実装する
  - 既存のダイアログサービス様式に従い、ダイアログの生成・表示・結果返却を担う
  - 編集結果を呼び出し側へ返し、既存ボタンへの反映に利用できるようにする
  - _Requirements: 3.1, 3.7_

- [x] 4. パネルのViewModelを実装する
- [x] 4.1 グリッドのセル射影とサイズ管理を実装する
  - サービスの状態をセル配列（行優先）へ射影し、行・列変更時に再構築する
  - 行・列の最小値補正と、縮小で範囲外となるボタンの確認・削除フローを実装する
  - _Requirements: 2.1, 2.2, 2.4, 2.5_

- [x] 4.2 送出・編集・クリアの操作と視覚フィードバックを実装する
  - 設定済みセルは押下で送出、未設定セルは押下で編集ダイアログを開く
  - 編集結果の反映、セルのクリア、送出時の一時ハイライト表示を実装する
  - 送信先が未設定・全無効のときの通知を行う
  - _Requirements: 3.1, 3.7, 4.1, 4.4, 4.5, 4.6_

- [x] 5. パネルのView（固定グリッド）を実装する
  - 行・列の入力欄と、行×列の固定グリッドにボタンを敷き詰める表示を実装する
  - 設定済み・未設定でボタン表示を区別し、編集・クリアの補助操作を提供する
  - ダークテーマ（カード・アクセント・枠）に準拠する
  - _Requirements: 2.1, 2.2, 4.5, 6.3_

- [x] 6. メイン画面への統合と配線を行う
- [x] 6.1 メインウィンドウをタブ構成に再編する
  - 上部にタブを新設し、既存全機能を「タイムコード」タブに内包、新規「OSCポン出し」タブを追加する
  - 起動時はタイムコードタブを初期選択にし、タブ切替でも背景処理（受信・リレー・キュー判定）が継続することを確認する
  - 新タブのViewにDIでViewModelを配線する
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 6.4_

- [x] 6.2 依存性注入にサービスとViewModelを登録する
  - パネルの管理サービス・ダイアログサービス・ViewModelをDIコンテナに登録する
  - _Requirements: 6.4_

- [x] 6.3 プロジェクトの保存・読込・新規にパネル状態を統合する
  - 保存時にパネル状態を集約し、読込時に復元してViewを同期、新規・全消去時に初期化する
  - パネルの変更が未保存フラグに反映されることを確認する
  - _Requirements: 5.1, 5.2, 5.4, 5.5_

- [x] 7. テストを追加する
- [x] 7.1 (P) 状態管理・送出サービスの単体テスト
  - 送出可否（設定済み・未設定・送信先全無効）の分岐、グリッド最小値の拒否、範囲外ボタンの列挙、セルCRUDの単一性を検証する
  - _Requirements: 2.2, 2.4, 2.5, 4.1, 4.4, 4.6_

- [x] 7.2 (P) 永続化のラウンドトリップと後方互換テスト
  - パネル設定を含むプロジェクトの保存→読込で、寸法とボタン（引数含む）が一致することを検証する
  - 新セクション欠落ファイルが既定値で読み込めることを検証する
  - _Requirements: 5.1, 5.2, 5.3, 5.5_

- [x] 7.3 (P) 引数テキスト記法ヘルパのテスト
  - int・float・string 複数のパース・整形ラウンドトリップと、不正トークンの無視を検証する
  - _Requirements: 3.4_
